# MakeItYap TTS — Text to Speech Converter

Official Windows installer downloads and release notes. Application source is
maintained separately in a private repository. Releases are built locally,
without GitHub Actions.

Visit [makeityap.com](https://www.makeityap.com/) for product information and
[the download page](https://www.makeityap.com/download.html) for installation
instructions. [Version 0.9.8](https://github.com/CoolerSheep/MakeItYapTTS-releases/releases/tag/v0.9.8)
is available now.

## Download for Windows

**[Download MakeItYapTTS-Installer.exe (65 MB)](https://github.com/CoolerSheep/MakeItYapTTS-releases/releases/latest/download/MakeItYapTTS-Installer.exe)**

Run this single file to download and install the latest release automatically.
The branded installer supports pause/resume, checks file integrity, and includes
the voice collection and Create a voice. Approximately 8.79 GB is downloaded
during setup. Speech generation works offline afterwards. Windows 10/11 x64;
no account, payment card or separate development tools are needed to begin.

The installation files live under **Releases**, not in the repository file list.
Use the web installer above for the simplest setup, or the offline files below.

## Offline installation

Download the versioned Setup executable and all six numbered runtime/model parts
into the same folder. Run Setup; it checks and extracts the parts automatically.
Each file is at most 1,900,000,000 bytes. The complete download is approximately
8.79 GB and includes all voices and Create a voice, without installation or
first-use downloads. The installer is unsigned.

## Updates and licences

Public installers are manually downloadable by everyone. The in-app updater
requires fresh online verification of an active paid licence. Early purchasers
receive 0.9.x and 1.x updates; version 2 is not included. Offline narration remains
available under the application's licence and trial conditions.

The application is proprietary; see [LICENSE.txt](LICENSE.txt) and the
[Terms of Use](https://www.makeityap.com/terms.html). Third-party components retain
their own licences. Release assets include their notices and corresponding-source
materials; the proprietary application licence does not restrict those rights.

The optional 1.21 GB source archive is separate from the installation files.
It contains pinned dependency sources, licence texts, checksums and rebuild
instructions; it is not required to install or use MakeItYapTTS.
